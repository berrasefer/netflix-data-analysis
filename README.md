# Netflix Data Analysis 

## Project Overview
This project explores a Netflix titles dataset using Python, pandas, and Matplotlib to identify patterns in content types, producing countries, release years, content ratings, and directors.

The goal is to practice exploratory data analysis (EDA), data quality assessment, data manipulation, and visualization.

## Technologies Used
- Python
- pandas
- Matplotlib
- Jupyter Notebook

## Analysis
The notebook covers:

1. **Dataset Exploration:** Examining the dataset structure and column information.
2. **Missing Values:** Identifying incomplete records.
3. **Content Distribution:** Comparing Movies and TV Shows.
4. **Country Analysis:** Identifying the most frequently represented production countries.
5. **Release Trends:** Exploring title counts by release year.
6. **Rating Distribution:** Examining common content classifications.
7. **Director Analysis:** Identifying frequently listed directors.
8. **Data Cleaning:** Demonstrating how missing values can be handled for selected analyses.

## Key Findings
- Movies appear more frequently than TV Shows.
- The United States is the most represented production country.
- Titles released after 2015 account for a substantial part of the dataset.
- TV-MA and TV-14 are among the most common content ratings.

These findings describe the dataset analyzed and should not be interpreted as Netflix's current catalog statistics.

## How to Run
1. Download the Jupyter Notebook.
2. Install pandas and Matplotlib.
3. Place the corresponding `netflix_titles.csv` dataset in the same directory as the notebook.
4. Run the notebook cells in order.
